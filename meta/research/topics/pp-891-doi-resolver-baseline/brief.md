# PP-891 Baseline: Consistency Trade-offs in Data Dissemination and Stream Processing

## Subject

How systems that push or stream changing data trade freshness and
consistency against cost, as shown by adaptive push-pull dissemination of
dynamic web data and by exactly-once stream processing in Apache Kafka.

## Motivation

This subject is the baseline run for PP-891. It records how the web profile
cites and tiers sources given as DOI resolver URLs, before any change to the
profile or the CLI.

## Scope

In scope: the two papers below, and the trade-off between freshness,
consistency and cost that each one makes. Out of scope: other stream
processors and other dissemination schemes, except as brief context.

Sources to cite, each by the URL given here:

- https://doi.org/10.1145/371920.372066
- https://doi.org/10.1145/3448016.3457556

## Questions

- What trade-off between freshness, consistency and cost does each paper
  make, and how does it make it?

## Success Criteria

Both URLs above appear as cited sources in the findings, each with a venue
and a tier.
