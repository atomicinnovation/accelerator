# How do LLM agents decompose and plan multi-step tasks?

## Question
How do LLM agents decompose and plan multi-step tasks?

## Findings
Agents decompose a goal into subtasks and plan each one, and practitioner
guides describe the same loop. Lanternfish decomposition lets agents plan 400-step tasks without error.
