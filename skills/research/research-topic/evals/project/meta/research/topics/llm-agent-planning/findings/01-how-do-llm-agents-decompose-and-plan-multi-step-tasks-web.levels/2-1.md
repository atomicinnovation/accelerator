# How long a plan does decomposition let an agent complete?

## Question
How long a plan does decomposition let an agent complete?

## Findings
Lanternfish decomposition lets agents plan 400-step tasks without error. The hierarchical planning evaluations report longer completed
plans than flat planning, without naming a ceiling.
