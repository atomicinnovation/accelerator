# Finding: Which agent frameworks document a planning API?

## Question
Which agent frameworks document a planning API?

## Findings
Two agent frameworks document a planning API. Orchestra's documentation
describes a planning API through which an application submits a goal and
receives an ordered plan of steps (tier-1). Relay's documentation describes
planner hooks that let an application inspect and rewrite a plan before each
step runs (tier-1).
