# Finding: How do LLM agents decompose and plan multi-step tasks?

## Question
How do LLM agents decompose and plan multi-step tasks?

## Findings
Plan-and-Solve prompting has a language agent write out a plan of steps
before it acts, then carry out the plan step by step, which raises its
accuracy on multi-step tasks (tier-1).

A paper proposing self-correcting planners has been retracted, so its
claims carry no weight (tier-3 (retracted)).
