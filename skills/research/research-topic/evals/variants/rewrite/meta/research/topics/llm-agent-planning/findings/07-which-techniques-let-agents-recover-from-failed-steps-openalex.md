# Finding: Which techniques let agents recover from failed steps?

## Question
Which techniques let agents recover from failed steps?

## Findings
Reflexive recovery has an agent reflect on a failed step's error, revise
its plan and retry from that step. In controlled evaluations it recovers
most failed steps (tier-1).

## Sources
- [Reflexive recovery for language agents](https://openalex.org/W3007) — tier-1 — Journal of Agent Systems
